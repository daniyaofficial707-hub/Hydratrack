# 💧 HydroTrack - Water Intake Tracker

A simple Python project to track and analyze daily water intake.

## 🚀 Features
- Log water intake
- Calculate daily total
- Track hydration goals
- Visualize data with graphs

## 🛠️ Tools Used
- Python
- Pandas
- Matplotlib

## 📊 Output
- Daily hydration summary
- Graphs showing water intake trends

## 🎯 Goal
Stay hydrated and build data science skills at the same time!
